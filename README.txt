Translation Practice Online - French with Haresh

To publish on Netlify: drag this whole folder (or the zip) onto app.netlify.com/drop.
The site is one file, index.html. It needs an internet connection only for the Google Fonts and works offline otherwise.
Each text opens at a link such as your-site.netlify.app/#zebres-translate (tabs: translate, tiles, strategy).

Booklet section: #booklet lists the Studio GCSE themes; each passage is at #read-b1-1 etc. Toggles: French order / English order / Show full English. Tap a phrase for its meaning.
